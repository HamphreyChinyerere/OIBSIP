# Oliver Mtukudzi Tribute Page

## OIBSIP Web Development & Designing Internship

**Level:** 2  
**Task:** 2 — Tribute Page

## Project Overview

This project is a responsive tribute webpage dedicated to Zimbabwean musician and cultural icon Oliver Mtukudzi.

The page presents a simple black-and-white editorial design highlighting his life, music, selected releases, achievements, and legacy.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Responsive Web Design

## Features

- Responsive hero section
- Oliver Mtukudzi biography
- Life and legacy timeline
- Selected music releases
- Styled quote section
- Black-and-white visual theme
- Serif and sans-serif typography
- Responsive layout for desktop, tablet, and mobile devices

## Responsive Design

The webpage is designed to adapt across:

- Desktop screens
- Tablets
- Mobile phones
- Small mobile devices

CSS media queries are used to adjust the hero section, timeline, typography, release grid, and overall layout.
